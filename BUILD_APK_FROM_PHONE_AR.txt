طريقة إنشاء APK عبر GitHub Actions (بدون تثبيت Android Studio):
1. يلزم حساب GitHub. افتح github.com وأنشئ مستودعًا جديدًا (New repository) باسم WaterTankerLog.
2. ارفع محتويات هذا المشروع إلى المستودع، مع مجلد .github الموجود فيه ملف workflow.
3. افتح تبويب Actions في المستودع، ثم اختر Build Android APK واضغط Run workflow (أو انتظر انتهاء التشغيل بعد رفع الملفات).
4. بعد نجاح التشغيل، افتح صفحة التشغيل الناجح وانزل إلى Artifacts، ثم نزّل WaterTankerLog-APK.zip.
5. فك ضغط الملف على الهاتف لتحصل على app-debug.apk، ثم افتحه للتثبيت. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر.
ملاحظة: هذا الأسلوب يبني APK على خوادم GitHub، لكنه يحتاج حساب GitHub ورفع المشروع وتشغيل workflow. لا يحتوي ملف ZIP نفسه على APK مبني مسبقًا.
